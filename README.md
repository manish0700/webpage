# Tikanath Gautam Multi-Page Portfolio

Static multi-page cybersecurity portfolio based on the supplied CV.

Pages:
- Home
- About
- Projects
- 5 individual project case studies
- Skills
- Education
- Contact

Privacy: phone number and email are intentionally NOT included. GitHub is the public contact route.

Run locally:
`python -m http.server 8000`

Then open `http://localhost:8000`.
